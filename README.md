# AeroStation 三维产品配置器

基于 Vue 3、TypeScript、Vite、Three.js、TresJS、Pinia、Tailwind CSS、Headless UI 和 Vue Router。

## 运行

```bash
corepack pnpm install
corepack pnpm dev
corepack pnpm build
```

## 已实现功能

- 由 Three.js 几何体程序化组成空气净化器模型，不依赖外部模型文件。
- 鼠标/触控拖拽旋转和缩放，移动端采用响应式布局。
- 颜色、材质、滤芯、续航、支架和控制环六组配置。
- 材质、滤芯、支架和电池选项包含真实依赖校验与自动修正。
- 价格及六个关键规格随配置实时更新。
- 主视角、正视、俯视和细节四种相机预设，切换使用逐帧平滑插值。
- 配置编码进分享链接，打开后还原为同一套选择。

## 规则包版本化

- 依赖规则、规格规则和物料价（基础价 + 选项价）收进带版本的规则包，版本只增不改，本地持久化。
- 保存配置时记下引用的规则包版本；分享链接同样携带版本，老顾客打开时按该版本计价，页内可切换对比现行版本。
- 规则包发布后，已保存配置逐项比对：受影响的报价和规格失效并按新版本重算，未受影响的沿用旧结果（每项结果带版本标记，重算留痕）。
- 两家门店可同时编辑同一规则包；版本被另一门店抢先发布时，改动保留为待确认冲突，列出双方差异，确认后把改动合并到线上版本再发布。
- 发布事务化：校验失败或发布中断（可模拟）时回滚到上一版，内存与持久化状态一致。
- 旧数据没有规则版本：首次启动用历史规则与物料价补成首版 v1，旧分享链接打开时自动补记为首版。
